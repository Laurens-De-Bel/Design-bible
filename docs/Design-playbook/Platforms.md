# Platforms

The build-up of a platform is fairly simple. There are a number of components that always recur, and all of them can be found in the following assembly:

`Standard_platforms, 23845114`.

When building a platform from the ground up (so not from a copy of an existing platform), it is recommended to work in a certain order. This decreases the chance that certain components are forgotten. An explanation of all the different components follows below, presented in the order in which the platform is to be assembled in Creo Elements.
